# The Hidden Christ | Bradley Hobbs

A Christian teaching project exploring the presence, identity, and revelation of Jesus Christ through Scripture and spiritual reflection.

## Live Website
https://brad-hobbswd.github.io/the-hidden-christ/

## Overview
The Hidden Christ by Bradley Hobbs is a journey from formation to revelation, inviting readers to discover Christ formed within surrendered lives and revealed through everyday faithfulness.
